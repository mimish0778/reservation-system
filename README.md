# 予約管理システム

PHP + MySQL で実装した、予約を管理するWebアプリケーションです。ユーザは予約の追加・削除を、管理者はユーザ・予約・投稿（おしらせ）の管理を行えます。

## 主な機能

**共通**
- ログイン / サインアップ / ログアウト
- ユーザ情報の編集（パスワード・生年月日・電話番号）

**ユーザ**
- 予約の追加（日付検索 → 空き時間帯の選択）
- 予約の削除
- おしらせの閲覧（宛先が自分または `everyone` のもの）

**管理者**
- ユーザ管理（削除 / 管理者権限の有効・無効）
- 予約管理（全ユーザの予約を削除）
- 投稿管理（おしらせの追加・削除、宛先指定）

画面数 11 / 機能数 11 / テーブル数 3。ユーザの権限（`isManager`）によって表示・操作できる機能が変わります。

## ファイル構成

```
.
├── reservation_system.php   … アプリ本体（完成版・1ファイル完結）
├── config.example.php       … DB接続設定のテンプレート
├── schema.sql               … データベース定義
└── prototypes/              … 開発途中の初期バージョン（参考）
    ├── main.php
    ├── signup.php
    └── questioner.php
```

本体は `reservation_system.php` 1ファイルで完結しています。`prototypes/` は開発過程で作った初期版で、動作には不要です。

## セットアップ

PHP と MySQL（MariaDB）が動く環境が必要です。

```bash
# 1. データベースを作成
mysql -u root -p < schema.sql

# 2. 接続設定を用意（config.php は git 管理対象外）
cp config.example.php config.php
#    config.php を開き、自分の環境の値に書き換える

# 3. Webサーバのドキュメントルートに配置してアクセス
#    例: http://localhost/reservation_system.php
```

## 設定と認証情報の扱い

DB接続情報はソースに直書きせず、`config.php` に分離しています。`config.php` は `.gitignore` に登録されているため、**実際のパスワードがリポジトリに公開されることはありません**。共有するのはプレースホルダ値の `config.example.php` のみです。

## 補足：GitHub での表示について

GitHub 上ではソースコードの**閲覧**はできますが、PHP は**実行されません**。実際に動作する画面を見せたい場合は、PHP が動くホスティング環境（XAMPP でのローカル公開など）が別途必要です。
