# 予約管理システム

PHP と MySQL で作った、1 時間単位の枠を予約できるシンプルな予約管理 Web アプリです。

一般ユーザーは空いている枠を探して予約・取り消しができ、管理者はユーザー・予約・おしらせをまとめて管理できます。本体は `reservation_system.php` 1 ファイルで、画面 11・機能 11・テーブル 3 の構成です。

## できること

**ユーザー**

- サインアップ / ログイン / ログアウト
- 日付を入力して空いている時間帯を探し、予約する（9:00〜19:00 の 1 時間枠）
- 自分の予約の確認・削除
- 自分宛て、または全員宛て（`everyone`）のおしらせを読む
- パスワード・生年月日・電話番号の変更

**管理者**

- ユーザーの削除、管理者権限の付与・解除
- 全ユーザーの予約の削除
- おしらせの投稿（宛先指定）・削除

管理者かどうかは `userTable` の `isManager` で決まり、メニューに出る機能が変わります。

## セットアップ

PHP と MySQL（または MariaDB）が動く環境が必要です。XAMPP などでも動きます。

```sh
# データベースとテーブルを作る
mysql -u root -p < schema.sql

# 接続設定を用意して、自分の環境に合わせて書き換える
cp config.example.php config.php
```

ファイル一式を Web サーバーのドキュメントルートに置いて、`http://localhost/reservation_system.php` を開いてください。

最初の管理者は、サインアップしたあと DB で `isManager` を `1` にするか、`schema.sql` 末尾のサンプル行のコメントを外して作ってください。

`config.php` は `.gitignore` に入れてあるので、実際のパスワードがコミットされることはありません。

## ファイル構成

```
reservation_system.php   アプリ本体
config.example.php       DB 接続設定のテンプレート
schema.sql               テーブル定義（提出ドキュメントから復元したもの。型は一部推定）
prototypes/              開発途中の初期版（動作には不要）
```

## セキュリティについて

学習用に作ったもので、インターネットに公開して使うことは想定していません。主に次の点が未対応です。

- SQL 文に入力値をそのまま埋め込んでいる（SQL インジェクション）
- パスワードを平文で保存している
- セッションを使わず、ユーザー名とパスワードを hidden フィールドで画面間に受け渡している
- 削除などの DB 操作を、ログイン・管理者権限の確認より前に実行している
- 出力時に HTML エスケープをしていない

公開するなら、プリペアドステートメント、`password_hash()`、セッション管理、操作ごとの権限チェックなどが必要です。
